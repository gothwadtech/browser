# Gothwad TV Browser — Windows Edition

Run Gothwad TV Browser directly on Windows 10 & Windows 11 with keyboard shortcuts, mouse hover/scroll, text selection, and multi-tabbed browsing.

---

## 🚀 Quick Start (Installation)

1. Download `gothwad-browser-windows-vX.X.X.zip` from GitHub Releases.
2. Extract the ZIP folder anywhere on your computer.
3. Double-click **`Install.bat`**.
   - This creates a **Desktop Shortcut** and **Start Menu Shortcut** with the browser icon.
   - Places browser files in `%LOCALAPPDATA%\GothwadBrowser`.

---

## 💻 Running the Browser on Windows

### Option 1: Windows 11 with WSA (Windows Subsystem for Android) — Recommended
1. If WSA is enabled on your Windows 11, double-click `Install.bat` or launch via the Desktop shortcut.
2. Alternatively, install [WSA-PacMan](https://github.com/LSPosed/WSA-PacMan/releases) for a seamless 1-click APK installer on Windows 11.

### Option 2: Android Emulator (BlueStacks, Nox, LDPlayer)
1. Drag and drop `app.apk` into your emulator window.
2. The browser is installed with full mouse & keyboard controls.

---

## 🗑️ Uninstalling

Double-click **`Uninstall.bat`** to cleanly remove all shortcuts and local app data.
