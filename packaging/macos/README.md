# Gothwad TV Browser — macOS Edition

Run Gothwad TV Browser on Apple Silicon (M1/M2/M3/M4) & Intel Macs with complete tabbed browsing, ad blocking, and keyboard/mouse precision.

---

## 🚀 Quick Start (Installation)

1. Download `gothwad-browser-macos-vX.X.X.zip` from GitHub Releases.
2. Unzip the file.
3. Drag **`Gothwad TV Browser.app`** into your **`Applications`** folder (or run `./install.sh`).
4. Launch it directly from **Launchpad** or **Spotlight**!

---

## 💻 Running on Mac

### Option 1: Android Studio / Emulator / Genymotion
1. Open any Android emulator on your Mac.
2. Launch **Gothwad TV Browser** from Applications. It will automatically detect the running emulator and install/launch the browser.

### Option 2: Connect via Wi-Fi to your Android TV
You can cast / run the browser directly on your Android TV from your Mac using wireless ADB:
```bash
adb connect <TV_IP_ADDRESS>:5555
```
Then click the Gothwad TV Browser app icon!

---

## 🗑️ Uninstalling

Run `./uninstall.sh` or drag `Gothwad TV Browser.app` from `/Applications` to Trash.
